# Проверка реализации

## Выполнено в рабочей среде

- Независимое чтение движка, бота и тестовых позиций: дополнительной ошибки правил не найдено.
- Найденная при интеграции сортировка неизменяемого списка ходов исправлена: бот сортирует копию.
- Движок и бот используют один контракт docs/API.md.
- Отдельное чтение интерфейса не выявило дополнительных ошибок управления состоянием и обработки устаревших ответов бота. Это статическая проверка.
- Проверен разбор 12 XML/storyboard/workspace-файлов, 3 JSON, 3 plist и 3 YAML. Во всех 4 заданиях CI есть подготовка канонических платформ. Проверена синтаксическая корректность android/gradlew через sh -n.

## Пока не подтверждено запуском

Для ПК дополнительно подготовлены `tool/build_windows.ps1` и workflow `Windows release ZIP`: они выполняют анализ, тесты, сборку Windows x64 и упаковку EXE вместе с DLL и data в `dist/Chess-2-Windows-x64.zip`. Их YAML/структура проверены, но Windows-сборка ещё не запускалась. Создание нового удалённого репозитория через подключённый GitHub было отклонено с `Resource not accessible by integration (createRepository)`; загрузка и облачная сборка требуют доступного пустого репозитория.

В этой среде нет Flutter/Dart SDK. Обычная загрузка не смогла подключиться к настроенному proxy:8080. Попытка получить дополнительный сетевой доступ была прервана до загрузки. Анализатор, Flutter-тесты, запуск UI и сборки здесь не выполнялись. Статическая проверка не заменяет компиляцию.

Есть тесты движка, бота и виджетов, но их успешное прохождение пока не заявляется. Нативные файлы подготовлены вручную; перед первой сборкой нужно пересоздать их установленным SDK, включая Gradle wrapper JAR. Сценарий ниже создаёт канонические платформы в отдельной временной папке и копирует только платформенные файлы. Он сохраняет lib/, test/, pubspec.yaml и README. Запускайте его до собственных изменений нативных runner-файлов.

```bash
dart tool/bootstrap_platforms.dart
flutter pub get
dart format lib test tool
flutter analyze
flutter test
flutter build web --release
```

Android проверяется на машине с Android SDK; Windows — на Windows с Visual Studio C++ Desktop; iOS — на macOS с Xcode. Подпись и магазинные публикации не настроены.
