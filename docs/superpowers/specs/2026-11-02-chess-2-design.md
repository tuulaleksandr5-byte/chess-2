# Шахматы 2.0 — рабочая спецификация

Пользователь разрешил реализацию: квадратное поле вместо круга, море убрано, два прямых ряда.

Flutter для Android, iOS, Windows; web для дополнительной демонстрации. Поле10×10,20 фигур каждой стороны: все18 типов, включая3 пешки. Русский интерфейс в тёмно-синем, слоновой кости и золоте. Бот и игра вдвоём на устройстве; подсветка ходов, история, отмена, переворот, новая игра и справочник.

Победа матом; короля не снимают. Нет рокировки. Есть взятие на проходе,16 вариантов превращения, пат, повторение, правило50 ходов и ничья двух королей. Полные правила и интерфейсы: docs/API.md.

Чистый Dart движок и бот отделены от Flutter. Бот работает вне UI isolate, его устаревшие ответы после сброса игнорируются. Ценности фигур предварительные. Нативные сборки подтверждаются только на доступной платформе.
