# Chess 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. User authorized continuous execution.

**Goal:** Playable Flutter chess variant for Android/iOS/Windows with square10×10 board and18 types.
**Architecture:** Immutable Dart engine, bounded search bot in compute isolate, responsive Flutter UI.
**Tech Stack:** Flutter stable, Dart3, Material and flutter_test; no runtime third-party packages.
**Spec:** docs/superpowers/specs/2026-11-02-chess-2-design.md

## Global Constraints
- Square10×10; no sea;20 units each, two straight ranks;6 classic+12 novel types.
- Russian UI; bot and same-device modes; checkmate wins; never capture kings.
- Shared contract docs/API.md; exclusive file ownership permits parallel implementation.

## Review Focus
- Pins, king safety and cannon screens.
- En passant exposing check and16 promotion choices.
- Stale bot responses after reset/undo/mode change.
- Small-phone/landscape overflow and readable pieces.
- Bot legality and terminal draws.
